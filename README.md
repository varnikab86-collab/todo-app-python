# Mera To-Do App - Python

Ek simple To-Do App jisme tasks save rehte hain.

## Features
- Task Add, Dekhna, Complete aur Delete kar sakte hain
- Tasks tasks.txt file me save hote hain, band karne ke baad bhi rehte hain
- Har task ke saath Date aur Status (Pending / Done) save hota hai

python todo.py
